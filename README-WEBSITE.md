# Website files — Road Network Integration Toolkit

This folder contains a responsive, multi-page GitHub Pages website.

## Pages
- `index.html` — Overview
- `features.html` — Features and coverage classification
- `methodologies.html` — Direct Merge, Clip + Snap, Targeted Snap
- `installation.html` — Installation and quick start
- `documentation.html` — Parameters, outputs and project resources

## Install in the plugin repository
Copy the website files and `assets/` folder into the repository root. Keep the existing `docs/images/` folder, `icon.png`, `LICENSE`, `help/`, plugin source and metadata files. The root `index.html` will become the GitHub Pages landing page when Pages is configured to deploy from the root of the `main` branch.

The pages intentionally reuse the existing SVG illustrations in `docs/images/`.
