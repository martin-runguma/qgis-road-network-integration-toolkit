about=Road Network Integration Toolkit is a QGIS plugin for integrating, aligning, and analysing road network datasets from different sources.
    
    The plugin provides three integration methodologies, dominant-buffer coverage classification, configurable spatial parameters, and a streamlined graphical interface for managing road network integration workflows.
    
    Key features:
    - Three road network integration methodologies.
    - Dominant-buffer coverage classification.
    - Redesigned graphical interface.
    - Multilingual interface and language selection.
    - QGIS background processing with cancellation support.
    - Live progress reporting and processing logs.
    - Input validation and coordinate reference system suggestions.
    - Configurable spatial buffers and integration tolerances.
    - GeoPackage, Shapefile, and File Geodatabase export.
    - GeoPackage feature ID collision protection.
    - Automatic addition of output layers to the current QGIS project.
    
    Compatible with QGIS 3.28 to 4.x, supporting Qt5 and Qt6 environments.
