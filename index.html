01 / Overview

Different sources.
One considered workflow.

Road network datasets rarely match perfectly. They can differ in geometry, spatial alignment, completeness and attribute structure.

The toolkit helps GIS analysts assess a secondary road network against a priority reference network, identify candidate roads not sufficiently represented, and integrate eligible features using a method selected for the task.

It runs within QGIS and uses the platform’s native vector, geometry, coordinate-transformation and data-writing capabilities.

03 / Methodology

Three methods.
Different geometry outcomes.

The priority network remains the reference. Each method determines how eligible secondary roads are added.

METHOD 0101

Direct Merge

Retains all priority roads and appends secondary features classified from missing_1 through missing_4. Secondary geometries are not trimmed or snapped.

Use when preserving the original secondary geometry is more important than removing overlaps or adjusting endpoints.

Retain + append
METHOD 0202

Clip + Snap

Subtracts the dissolved priority-buffer mask from eligible secondary roads. It then creates regularly spaced anchors along priority roads and snaps remaining line-part endpoints to the nearest anchor within the configured snapping distance.

Use when covered portions should be removed and nearby endpoints should connect to the priority network.

Trim + anchor snap
METHOD 0303

Targeted Snap

Trims eligible roads, derives local snap targets from priority roads near the secondary-road overlap context, and tries local midpoints, then local endpoints, before a global nearest-target fallback. missing_1 roads are added without snapping.

Use when endpoint connections should be guided by local overlap context rather than only globally spaced anchors.

04 / Coverage logic

Classify before
you integrate.

The classifier uses the remaining-length ratio after the largest overlap with one individual priority-road buffer. It does not sum overlaps from separate buffers.

remaining ratio = (road length − largest single-buffer overlap) / road length

Remaining ratioClassInterpretationAdded?
0–0.01missing_aEffectively fully coveredNo
>0.01–<0.25missing_bMore than 75% coveredNo
Exactly 0.25—Unclassified boundaryNo
>0.25–0.50missing_425–50% remainsYes
>0.50–0.75missing_350–75% remainsYes
>0.75–<1missing_2More than 75% remainsYes
Exactly 1missing_1No measured overlapYes

Thresholds reflect the legacy classification rules implemented in the plugin.

05 / Workflow

A guided path from
inputs to output.

The plugin brings preparation, classification, integration and export into one QGIS workflow.

  1. 01

    Select source layers

    Choose priority roads, secondary roads and a polygon study-area boundary.

  2. 02

    Set analysis parameters

    Choose a projected CRS and review the spatial distances and tolerances.

  3. 03

    Assess coverage

    Prepare the road data and classify secondary features by buffer overlap.

  4. 04

    Choose a method

    Apply Direct Merge, Clip + Snap or Targeted Snap.

  5. 05

    Run and monitor

    Follow progress and the processing log; cancellation is available at safe checkpoints.

  6. 06

    Review and export

    Write the final network and optionally retain intermediate diagnostic layers.

07 / Installation & compatibility

Ready for your
QGIS workspace.

The plugin uses the Python, PyQGIS, Qt and GDAL components supplied by the active QGIS installation. No separate GeoPandas or Shapely installation is required.

01

Open the Plugin Manager

In QGIS, choose Plugins → Manage and Install Plugins…

02

Find the toolkit

Search for Road Network Merging and Alignment Toolkit.

03

Install and enable

Select the plugin, install it, then open it from the Plugins menu or toolbar.

ZIP

Prefer a package?

Download the ZIP package and use Install from ZIP in the Plugin Manager.
